# Support

Use GitHub Issues for reproducible bugs, documentation gaps, and focused
feature proposals. Include the affected commit or release, platform, expected
result, actual result, and a minimal reproduction using synthetic data.

This project cannot provide investment advice, strategy-profit guarantees,
account recovery, or custody support. Reconcile positions and orders directly
in WEEX before troubleshooting automation.

Never post credentials, OAuth tokens, session cookies, database URLs, private
order history, screenshots containing account data, or production
infrastructure identifiers. Report possible vulnerabilities privately through
[SECURITY.md](SECURITY.md).
