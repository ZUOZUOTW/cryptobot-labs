# CryptoBot Labs 高擬真網站設計規格

日期：2026-07-10

狀態：已確認，待實作計畫

介面語言：繁體中文

## 1. 產品目標

CryptoBot Labs 是一個以 WEEX 為唯一交易所的自動交易機器人探索與組裝平台。首版交付為高擬真互動原型，主要目的如下：

- 讓沒有程式與架設經驗的使用者理解、選擇、修改與下載交易策略。
- 以完整的正式產品資訊架構，作為未來實盤版本的 UI 基礎。
- 展示 10 組經典策略機器人的模擬回測績效。
- 支援多策略積木組合、參數調整與 JavaScript 策略輸入。
- 產生可下載、可重新匯入的完整策略包。
- 在所有交易所相關設定中嚴格限制為 WEEX。

首版不接收 API Key、不連接真實帳戶、不執行真實下單，也不在瀏覽器執行使用者提供的 JavaScript。所有績效均為可重現的模擬資料，且必須清楚標示「模擬回測資料，不代表未來績效」。

## 2. 使用者與成功標準

### 主要使用者

- 沒有寫程式經驗，但想理解自動交易的新手。
- 沒有部署交易機器人經驗，希望從預設策略開始的使用者。
- 想以圖形化方式組合策略，再查看績效變化的進階使用者。
- 想貼上 JavaScript 策略邏輯並下載策略包的量化使用者。

### 首版成功標準

- 新手能在無需外部教學的情況下完成「挑選 → 理解 → 自訂 → 回測 → 下載」。
- 使用者能同時組合多個策略模組並調整參數。
- 10 組預設機器人都能顯示完整、互相可比較的回測資訊。
- 所有可下載設定都宣告 `WEEX` 為唯一交易所；其他交易所識別字會被阻擋。
- 網站在桌面與手機上皆可操作，並支援鍵盤與減少動態效果設定。

## 3. 已選擇的產品方案

採用多頁式產品原型，而非單頁展示或控制台優先模式。多頁架構能清楚分隔探索、比較、組裝與下載任務，並保留未來接入帳號、後端、WEEX 行情及執行器的擴充空間。

### 主要使用流程

1. 從首頁理解 CryptoBot Labs 與 WEEX 專屬限制。
2. 在機器人市場依現貨、合約、風險與績效篩選機器人。
3. 在詳情頁閱讀策略原理與模擬回測結果。
4. 選擇快速下載官方版本，或複製到組裝車間自訂。
5. 在組裝車間加入多個策略積木、調整參數及風控。
6. 執行模擬回測並檢查自然語言策略摘要。
7. 下載完整策略包，或重新匯入策略包繼續修改。

## 4. 資訊架構

### `/` 品牌入口

- 華麗的 Orbital Lab 首屏與核心品牌主張。
- 展示「零代碼策略積木」、「JavaScript 模式」、「模擬回測」、「WEEX 專屬」四項核心能力。
- 以動態績效卡介紹熱門機器人與排行榜。
- 用三步驟呈現挑選、組裝、下載流程。
- 主要行動為「探索機器人」與「開始組裝」。

### `/bots` 機器人市場

- 顯示 10 組預設策略卡片。
- 支援現貨／合約、風險、交易週期及策略類型篩選。
- 支援依累積收益、最大回撤、勝率、穩定度排序。
- 卡片顯示迷你收益曲線、關鍵績效、風險標籤及 WEEX 標誌。
- 每張卡片提供「查看詳情」與「快速下載」。

### `/bots/:id` 機器人詳情

- 顯示累積收益曲線與基準比較。
- 顯示累積收益、年化報酬、最大回撤、勝率、盈虧比、夏普比率、交易次數、運行天數與風險等級。
- 顯示月度表現、交易方向分布、策略原理、適用市場及風險說明。
- 提供「下載官方策略包」與「複製到組裝車間」。

### `/leaderboard` 績效排行榜

- 提供 30 天、90 天與 1 年週期切換。
- 可依收益、穩定度、回撤與風險調整報酬排序。
- 以動態排名、比較柱狀圖、收益曲線及風險散點視圖呈現資料。
- 排名變動須平滑過渡，避免重新排序時失去上下文。

### `/workshop` 組裝車間

- 提供「快速組裝」與「JavaScript」兩種模式。
- 快速組裝採策略積木與步驟式引導。
- JavaScript 模式提供範例、靜態檢查與策略摘要，不執行輸入程式。
- 支援從預設機器人複製、從空白建立，以及匯入已下載策略包。
- 最後一步為預覽、模擬回測與下載，不使用「啟動實盤」措辭。

## 5. 視覺與動態系統

採用已確認的 A 方案「Orbital Lab」。

### 視覺語言

- 深黑石墨背景，主色為電紫與冰藍，成功狀態使用薄荷綠。
- 橘紅只用於警告、高風險與衝突，不作裝飾色。
- 半透明玻璃面板、細緻發光邊線、柔和噪點與軌道網格形成策略實驗室質感。
- 標題採寬闊俐落的科技字型；中文內文以高可讀性為優先。
- 圖表、策略積木與績效數字使用一致的色彩語意。

### 動態效果

- 首屏有緩慢旋轉的策略核心、環繞軌道、浮動績效卡及輕微游標景深差。
- 頁面轉場使用短暫光帶掃描，不阻塞導航。
- 卡片懸停時浮起並顯示迷你收益曲線與次要指標。
- 排行榜排序、圖表切換及數值更新使用連續動畫。
- 策略積木加入、移除與排序有明確回饋；相容積木使用藍紫光，不相容積木使用警示脈衝。
- 回測使用短暫的訊號流動畫，完成後展開績效面板。
- `prefers-reduced-motion` 下移除粒子、景深與大型轉場，只保留必要狀態變化。
- 手機版降低粒子數量與玻璃模糊強度，優先確保效能與觸控準確度。

## 6. 組裝車間設計

### 快速組裝模式

策略模組分為五個區域：

1. 進場訊號
2. 確認條件
3. 出場規則
4. 倉位管理
5. 停損停利

使用者可在每個區域選取多個策略積木。條件群組支援「符合全部條件」與「符合任一條件」。積木可點選加入並拖曳排序。

每個積木提供參數面板，涵蓋策略週期、門檻、時間框架、投入比例、槓桿與風控。新手模式以滑桿、選單、預設值與白話說明呈現；進階值可使用數字輸入精確調整。

系統持續產生自然語言摘要，例如：「當 15 分鐘 RSI 低於 30，且價格重新站上 20 期均線時進場；每次投入 10%，下跌 3% 停損。」使用者不必閱讀程式碼也能確認邏輯。

內建快速組合範本：

- 穩健趨勢
- 震盪低買高賣
- 突破追蹤
- 定投與回撤加碼
- 低槓桿風控

範本載入後仍可自由加入、移除與調整積木。

### JavaScript 模式

- 提供 WEEX 專屬策略函式範例與欄位說明。
- 提供基本語法檢查並標示問題行數。
- 以靜態分析偵測常見策略條件，用於產生自然語言摘要與模擬結果。
- 偵測 `Binance`、`OKX`、`Bybit`、`Coinbase` 等非 WEEX 交易所名稱或網域時阻擋回測與匯出。
- 不使用 `eval`、`Function` 或其他方式執行使用者程式。

### 衝突與風險提示

- 缺少進場或出場規則時禁止回測。
- 邏輯條件互相矛盾時指出衝突積木。
- 參數超出合理範圍時提供原因與建議值。
- 合約槓桿提高時同步更新風險等級與回撤警告。
- 修正錯誤不會清除其他策略設定。

## 7. 預設策略機器人

### 現貨策略

1. **Orbit DCA**：分批定投與回撤加碼。
2. **Grid Navigator**：震盪網格交易。
3. **Golden Cross**：雙均線趨勢跟隨。
4. **RSI Rebound**：超賣反彈。
5. **Bollinger Pulse**：布林通道壓縮突破。

### 合約策略

1. **Momentum Forge**：MACD 動能順勢。
2. **Breakout Hunter**：區間突破追蹤。
3. **ATR Sentinel**：波動率停損趨勢策略。
4. **Dual-Side Ranger**：多空雙向區間策略。
5. **Leverage Guardian**：低槓桿風控組合。

每台機器人都必須包含：名稱、短描述、現貨／合約分類、交易週期、策略標籤、風險等級、模擬績效、收益曲線、月度表現、策略原理、適用情境與風險說明。

## 8. 模擬回測

首版採可重現的前端模擬引擎。同一策略組合、參數、交易對及期間必須產生相同結果。模擬引擎以固定種子與策略參數產生收益序列，再計算下列指標：

- 累積收益
- 年化報酬
- 最大回撤
- 勝率
- 盈虧比
- 夏普比率
- 交易次數
- 運行天數
- 風險等級

參數改動後，收益曲線與統計數據同步更新。此引擎的目標是呈現可信的產品交互與資料關係，不宣稱使用真實歷史行情。所有回測區域均持續顯示模擬資料標籤與風險聲明。

## 9. 下載與匯入策略包

下載是網站的核心使用方式。每台機器人提供：

- **快速下載**：下載官方預設參數版本。
- **自訂後下載**：複製到組裝車間，完成多策略組合、調參與回測後下載。

下載格式為 `.zip`，包含：

- `bot-config.json`：市場、交易對、時間週期、策略組合、參數與風控設定。
- `strategy.js`：對應 JavaScript 策略範例。
- `backtest-report.json`：本次模擬回測結果。
- `README-zh-TW.md`：繁體中文說明、風險提醒與未來匯入方式。
- `manifest.json`：套件版本、建立時間及固定的 `exchange: "WEEX"` 宣告。

匯出前必須執行下列驗證：

- 交易所為 WEEX。
- 至少有一組有效進場與出場規則。
- 參數在允許範圍內。
- JavaScript 未包含非 WEEX 交易所識別字。
- 模擬回測已成功完成。

組裝車間提供「匯入策略包」。匯入時驗證檔案結構、版本與 WEEX 宣告；有效套件可重新編輯與模擬回測。首版套件不能獨立執行實盤，README 與下載前確認畫面必須清楚說明此限制。

## 10. 資料與狀態

- 預設機器人與績效資料由本地 TypeScript 資料集提供。
- 自建機器人、收藏、最近篩選與草稿儲存在瀏覽器本機。
- 不收集個人資料、API Key 或帳戶資料。
- 不呼叫真實交易或帳戶端點。
- 本機儲存失敗時保留目前記憶體狀態，提示使用者立即下載策略包。
- 清除網站資料會移除本機草稿；介面需明確提醒使用者下載備份。

## 11. WEEX 專屬限制

所有交易所選擇、套件資訊、策略範例與未來連線預覽都固定為 WEEX，不提供其他交易所選項。首版可連結官方資料作為使用者參考：

- [WEEX API 入口](https://www.weex.com/weex-API)
- [WEEX Spot API Introduction](https://www.weex.com/api-doc/spot/introduction/APIBriefIntroduction)

WEEX 官方頁面目前說明現貨與 USDT-M 合約 API，並提供 REST API、WebSocket、市場行情、K 線、訂單簿及即時成交等能力。首版只呈現未來整合入口，不送出相關請求。

## 12. 技術架構

- React 與 TypeScript 建立頁面與元件。
- 多頁路由對應首頁、機器人市場、詳情、排行榜及組裝車間。
- 共用設計系統管理色彩、間距、玻璃面板、按鈕、標籤、狀態與動態效果。
- 策略資料、驗證規則、模擬回測與策略包序列化拆分為獨立模組。
- 本機儲存只負責草稿、收藏與偏好，不儲存敏感資料。
- 策略包在瀏覽器端產生與解析。
- 圖表元件共用同一資料格式，確保市場、詳情與排行榜顯示一致。

## 13. 錯誤處理

- 沒有選擇必要規則時，行動按鈕停用並顯示缺少項目。
- 參數不合理、條件衝突或槓桿過高時，顯示原因與修正建議。
- JavaScript 語法錯誤時顯示對應行數，不清除輸入內容。
- 偵測到非 WEEX 交易所時直接阻擋回測與匯出。
- 模擬回測失敗時保留完整設定並允許重試。
- 匯入的 ZIP 缺少必要檔案或版本不支援時，列出具體問題。
- 下載失敗時提供重試與分別下載單一檔案的備援操作。

## 14. 無障礙與響應式設計

- 所有主要操作都能以鍵盤完成。
- 策略積木除拖曳外，提供鍵盤可用的加入、移除與上下移動按鈕。
- 圖表使用文字摘要補充，關鍵資訊不只依賴顏色。
- 互動元件具備清楚的焦點狀態與可讀標籤。
- 高風險、錯誤與成功狀態同時使用圖示、文字及色彩。
- 桌面版以寬幅儀表板呈現；手機版改為單欄卡片與底部操作列。
- 支援 `prefers-reduced-motion`。

## 15. 驗證計畫

### 邏輯驗證

- 固定輸入產生固定模擬結果。
- 指標計算不產生無效數字或不合理範圍。
- 多策略 AND／OR 組合可正確序列化與還原。
- 10 組預設機器人資料欄位完整且 ID 唯一。
- 非 WEEX 設定與識別字必須被阻擋。
- 策略包匯出後可重新匯入並保留設定。

### 介面驗證

- 五個主要頁面可正常導航。
- 篩選、排序、收藏、快速下載與複製到車間可操作。
- 組裝、調參、自然語言摘要、回測與下載流程完整。
- 鍵盤、觸控與手機版面可用。
- 減少動畫模式生效。
- 建置成功且不包含真實交易憑證或非 WEEX 交易端點。

## 16. 明確不在首版範圍

- 使用者註冊、登入與權限。
- 付款、訂閱與商業方案。
- 雲端資料庫與跨裝置同步。
- API Key 輸入、加密、儲存與輪替。
- 真實 WEEX 行情、帳戶查詢、下單或撤單。
- 使用者 JavaScript 的伺服器沙箱執行。
- 長時間運行的策略排程器與實盤監控。
- 可直接執行真實交易的下載程式或桌面執行器。

上述功能屬於第二階段，必須以安全後端、隔離的策略執行環境、金鑰管理、風控與審計紀錄另行設計。
